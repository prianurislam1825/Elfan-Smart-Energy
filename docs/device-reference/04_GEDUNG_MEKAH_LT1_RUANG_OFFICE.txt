### F. Rancangan Integrasi ELFAN

Untuk aplikasi ELFAN, perangkat ditampilkan sebagai satu perangkat lampu dengan dua kontrol terpisah.

Lampu Gedung Makkah

Lampu Kantor

Gang 1

Saklar Lampu Kantor

Gang 2

Masing-masing gang memiliki kontrol ON/OFF dan timer sendiri.

Rancangan fungsi aplikasi:

1. ON/OFF Lampu Kantor.
2. ON/OFF Saklar Lampu Kantor.
3. Timer untuk masing-masing gang.
4. Menampilkan status aktual masing-masing gang.
5. Kontrol kedua gang secara independen.

### G. Mapping DP untuk Backend

```
{
  "device_id": "a3ee5390cd39c5b0abq6j0",

  "capabilities": {
    "gang_1": {
      "name": "Lampu Kantor",
      "switch_dp": "switch_1",
      "timer_dp": "countdown_1"
    },
    "gang_2": {
      "name": "Saklar Lampu Kantor",
      "switch_dp": "switch_2",

    }
  }

```

Mapping di atas merupakan rancangan konfigurasi internal ELFAN, bukan payload resmi Tuya.

### H. Catatan Implementasi

- Kedua gang harus diperlakukan sebagai dua kanal kontrol yang berbeda.
- Perubahan status gang 1 tidak boleh memengaruhi gang 2.
- Timer masing-masing gang harus berdiri sendiri.
- `switch_1` dan `switch_2` digunakan untuk mengirim sekaligus membaca status sakelar.
- Fitur `cycle_time`, `random_time`, dan `switch_inching` belum perlu ditampilkan pada antarmuka utama ELFAN.
- Nilai status awal pada data perangkat yang diberikan adalah kedua sakelar `false`, kedua timer `0`, dan `switch_backlight` `false`.

Dokumentasi perangkat pertama selesai
