### B. Fungsi dan Mekanisme

Smart Plug digunakan sebagai pemutus dan penyambung aliran listrik AC yang dikendalikan melalui perangkat IR.

Keduanya mengontrol satu unit AC yang sama, tetapi memiliki fungsi berbeda:

1. IR AC: Mengontrol fungsi AC seperti Power, suhu, mode, dan kecepatan kipas.
2. Smart Plug: Memutus atau menyambungkan sumber listrik AC secara langsung.

Dengan mekanisme tersebut, ketika Smart Plug dimatikan, AC akan kehilangan suplai listrik sehingga tidak dapat dioperasikan melalui remote maupun IR.

Catatan implementasi: Smart Plug dan IR harus diperlakukan sebagai dua perangkat berbeda dalam sistem, tetapi dikelompokkan dalam satu perangkat fisik AC pada aplikasi ELFAN.

### C. Fitur Perangkat

Berdasarkan data Standard Instruction Set dan Standard Status Set, perangkat memiliki fitur berikut:

| Fitur                 | Data Point          | Tipe    | Keterangan                                            |
| --------------------- | ------------------- | ------- | ----------------------------------------------------- |
| Power                 | `switch_1`          | Boolean | Menghidupkan atau mematikan aliran listrik            |
| Countdown             | `countdown_1`       | Integer | Timer hitung mundur dalam detik                       |
| Relay Status          | `relay_status`      | Enum    | Pengaturan kondisi relay                              |
| Light Mode            | `light_mode`        | Enum    | Pengaturan mode indikator                             |
| Child Lock            | `child_lock`        | Boolean | Mengaktifkan atau menonaktifkan kunci perangkat       |
| Cycle Time            | `cycle_time`        | String  | Pengaturan waktu siklus                               |
| Random Time           | `random_time`       | String  | Pengaturan waktu acak                                 |
| Inching               | `switch_inching`    | String  | Pengaturan pemutusan otomatis setelah durasi tertentu |
| Overcharge Protection | `overcharge_switch` | Boolean | Pengaturan proteksi daya berlebih                     |

### D. Detail Data Point

1\. Power – `switch_1`

- Tipe: Boolean
- Nilai: `true` / `false`
- `true`: Smart Plug aktif, aliran listrik tersambung.
- `false`: Smart Plug nonaktif, aliran listrik terputus.

2\. Countdown – `countdown_1`

- Tipe: Integer
- Satuan: Detik
- Minimum: 0
- Maksimum: 86.400 detik
- Step: 1 detik

Digunakan untuk mengatur durasi sebelum Smart Plug menjalankan perubahan kondisi sesuai mekanisme countdown perangkat.

3\. Relay Status – `relay_status`

- Tipe: Enum
- Pilihan:
  - `power_off`
  - `power_on`
  - `last`

4\. Light Mode – `light_mode`

- Tipe: Enum
- Pilihan:
  - `relay`
  - `pos`
  - `none`

5\. Child Lock – `child_lock`

- Tipe: Boolean
- Nilai: `true` / `false`

6\. Cycle Time – `cycle_time`

- Tipe: String
- Digunakan untuk konfigurasi pengaturan waktu siklus.

7\. Random Time – `random_time`

- Tipe: String
- Digunakan untuk konfigurasi pengaturan waktu acak.

8\. Inching – `switch_inching`

- Tipe: String
- Digunakan untuk mengatur pemutusan otomatis setelah durasi tertentu.

9\. Overcharge Protection – `overcharge_switch`

- Tipe: Boolean
- Nilai: `true` / `false`

Data tersebut dapat digunakan ELFAN untuk menampilkan informasi konsumsi listrik AC.

### F. Kebutuhan Implementasi pada Aplikasi ELFAN

Smart Plug tidak perlu ditampilkan sebagai perangkat AC terpisah. Perangkat ini menjadi bagian dari kontrol AC Alwustho Office.

Rancangan fungsi pada aplikasi:

| Kontrol                | Fungsi                                       |
| ---------------------- | -------------------------------------------- |
| Power AC melalui IR    | Mengontrol operasional AC                    |
| Power Supply AC        | Menghidupkan atau memutus Smart Plug         |
| Timer                  | Mengatur countdown Smart Plug                |
| Electricity Monitoring | Menampilkan tegangan, arus, daya, dan energi |
| Child Lock             | Mengunci kontrol Smart Plug                  |

Mekanisme kontrol yang perlu diperhatikan:

- Ketika Smart Plug OFF, perintah IR tidak dapat mengoperasikan AC karena suplai listrik terputus.
- Ketika Smart Plug ON, AC mendapatkan suplai listrik dan dapat dikendalikan melalui IR.
- Status Smart Plug dan status AC dari IR harus disimpan sebagai dua status berbeda. Keduanya tidak boleh dianggap selalu identik.

Implementasi pada backend perlu membedakan dua jenis komunikasi:

- Smart Plug: Mengontrol suplai listrik AC secara langsung melalui Tuya Cloud.

Alur pengendalian:

1. ELFAN menerima perintah pengguna.
2. Backend mengidentifikasi perangkat tujuan, yaitu AC atau kipas.
3. Backend mengambil konfigurasi perintah dari sub-device yang sesuai.
4. IR Remote mengirimkan sinyal inframerah ke perangkat tujuan.
5. Untuk pemutusan listrik AC, ELFAN menggunakan Smart Plug, bukan perintah Power Off dari IR.

| `PowerOn`  | STRING | `PowerOn`  |
| `PowerOff` | STRING | `PowerOff` |
| `T`        | ENUM   | 16–30      |
| `M`        | ENUM   | 0–4        |
| `F`        | ENUM   | 0–3        |

Keterangan:

- `PowerOn`: Mengirim perintah untuk menghidupkan AC.
- `PowerOff`: Mengirim perintah untuk mematikan AC.
- `T`: Mengatur suhu AC.
- `M`: Mengatur mode AC.
- `F`: Mengatur kecepatan kipas AC.

### 4. Standard Status Set

Data status yang dilaporkan perangkat:

| Code    | Type    | Nilai                |
| ------- | ------- | -------------------- |
| `power` | BOOLEAN | Status hidup/mati AC |
| `temp`  | ENUM    | 16–30                |
| `mode`  | ENUM    | 0–4                  |
| `wind`  | ENUM    | 0–3                  |

Keterangan:

- `power`: Status daya AC.
- `temp`: Suhu yang sedang diatur.
- `mode`: Mode operasi AC.
- `wind`: Kecepatan kipas AC.

### 5. Integrasi dengan Smart Plug

AC Alwustho Office juga menggunakan Smart Plug sebagai pemutus daya listrik utama.

Mekanisme pengoperasiannya mengikuti konsep AC Ruang Meeting Gedung Madinah:

1. IR Controller digunakan untuk menghidupkan, mematikan melalui perintah IR, mengatur suhu, mode, dan kecepatan kipas.
2. Smart Plug digunakan untuk memutus atau menyambungkan suplai listrik AC secara langsung.
3. Smart Plug dapat mematikan AC sepenuhnya sehingga AC tidak dapat dioperasikan melalui remote maupun IR ketika suplai listrik terputus.

Smart Plug AC Alwustho Office sudah didokumentasikan sebelumnya dengan Device ID `a3fc5edf44f5ebf6d5kwct`.

### 6. Rancangan Tampilan ELFAN Mobile

AC dan Smart Plug ditampilkan sebagai satu perangkat AC dalam aplikasi, bukan sebagai dua perangkat terpisah.

Menu AC Alwustho Office

- Tombol Power AC.
- Pengaturan suhu.
- Pengaturan mode.
- Pengaturan kecepatan kipas.
- Kontrol suplai listrik Smart Plug.

Catatan implementasi: Status AC dari IR dan status suplai listrik Smart Plug harus dikelola sebagai dua status berbeda. Ketika Smart Plug OFF, kontrol IR tidak boleh dianggap berhasil menghidupkan AC.
