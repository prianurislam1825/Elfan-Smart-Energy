### 2. Deskripsi Perangkat

Lampu Sorot Aula merupakan perangkat sakelar pintar dengan empat kanal (4 Gang) yang digunakan untuk mengendalikan lampu sorot di Aula Gedung Madinah lantai 1.

Perangkat terhubung ke platform Tuya dan dapat dikendalikan melalui aplikasi Smart Life. Setiap kanal memiliki kontrol ON/OFF secara individual.

### 3. Konfigurasi Data Point (DP)

#### 3.1. Switch Control

| Data Point | Tipe | Fungsi |
|---|---|---|
| `switch_1` | Boolean | Kontrol sakelar 1 |
| `switch_2` | Boolean | Kontrol sakelar 2 |
| `switch_3` | Boolean | Kontrol sakelar 3 |
| `switch_4` | Boolean | Kontrol sakelar 4 |

Nilai:
- `true` = ON
- `false` = OFF

#### 3.2. Countdown

| Data Point | Tipe | Rentang | Fungsi |
|---|---|---|---|
| `countdown_1` | Integer | 0–86.400 detik | Countdown sakelar 1 |
| `countdown_2` | Integer | 0–86.400 detik | Countdown sakelar 2 |
| `countdown_3` | Integer | 0–86.400 detik | Countdown sakelar 3 |
| `countdown_4` | Integer | 0–86.400 detik | Countdown sakelar 4 |

Ketentuan:
- Satuan waktu menggunakan detik.
- Nilai minimum: 0 detik.
- Nilai maksimum: 86.400 detik (24 jam).
- Setiap kanal memiliki parameter countdown tersendiri.
