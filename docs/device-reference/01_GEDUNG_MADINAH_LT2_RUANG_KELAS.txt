#### 6.1 Countdown

Setiap kanal mempunyai DP countdown masing-masing:

| Kanal | DP Code | Rentang |
|---|---|---|
| Switch 1 | `countdown_1` | 0–86400 detik |
| Switch 2 | `countdown_2` | 0–86400 detik |
| Switch 3 | `countdown_3` | 0–86400 detik |
| Switch 4 | `countdown_4` | 0–86400 detik |

Contoh konversi durasi:
- 1 menit = 60 detik
- 5 menit = 300 detik
- 10 menit = 600 detik
- 30 menit = 1800 detik
- 1 jam = 3600 detik
- 12 jam = 43200 detik
- 24 jam = 86400 detik

Efek akhir countdown terhadap kondisi switch belum dikonfirmasi melalui pengujian langsung. Jangan mengasumsikan apakah countdown mengubah kanal menjadi ON atau OFF sebelum perilaku perangkat diuji.

#### 6.2 Timer

Menu Timer terlihat pada antarmuka Smart Life. Detail jenis jadwal, pengulangan, konfigurasi, serta mekanisme pengelolaan melalui Tuya Cloud API belum tersedia pada data pemeriksaan perangkat ini.

Timer terjadwal harus dibedakan dari DP countdown. Keberadaan menu Timer pada aplikasi tidak dengan sendirinya membuktikan bahwa seluruh pengaturan tersebut dapat dibuat atau dibaca melalui DP countdown.
