# API Reference — Growatt PLTS Inverter> **Label:** `BERDASARKAN DOKUMENTASI` (sumber: `api-plts-inverter.pdf` / `api-plts-inverter.txt`, halaman 4–32).  > **Catatan:** dokumen ini adalah contoh antarmuka dari tahun 2016. Alamat dan format tetap disebutkan di sini sebagai bukti audit, tetapi **bukan jaminan endpoint masih berfungsi di production**. Uji koneksi di environment yang diizinkan sebelum integrasi.---## Dasar Panggilan- Base URL contoh dari dokumen: `http://test.growatt.com/v1/`- Base URL di `server.cjs` dan `README.md` dikonfigurasi dari `config.json` → `growatt.baseUrl`.- Kemungkinan base URL lain yang disebutkan di konfigurasi/tool:  - `http://test.growatt.com/v1`  - `http://openapi.growatt.com/v1`  - `https://open.growatt.com/v1` (disebutkan dalam `verify-device.cjs` sebagai opsi environment)- Tidak ada `Authorization: Bearer` yang terlihat.
