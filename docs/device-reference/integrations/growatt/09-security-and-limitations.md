Token tidak boleh tereksposRepository `monitoring-inverter` menutupkannya dengan field token dalam:

- `config.json`
- `config.local.json``config.local.json` berisi:

```json
{
  "growatt": {
    "baseUrl": "http://openapi.growatt.com/v1",
    "token": "<GROWATT_TOKEN>",
    "devices": ["NUEICLS03V"],
    "pollIntervalMs": 30000,
    "requestTimeoutMs": 15000
  }
}
```
> 🛑 Token di file konfigurasi ini **TIDAK** boleh dimasukkan ke dokumen integrasi, GitHub, GitHub Action, CI/CD, Flutter, atau repositori publik. Korespondensi bentuk yang ditulis dengan `<GROWATT_TOKEN>` hanya sebagai contoh, bukan nilai asli. Korespondensi bentuk yang ditulis dengan `<GROWATT_TOKEN>` hanya sebagai contoh, bukan nilai asli. Validasi `GROWATT_TOKEN` tidak boleh kosong sebelum mode growatt aktif.---## 2. Jangan kirim token ke FlutterFlutter/frontend **tidak boleh** menerima atau mengirim token Growatt.Alasan:- Token harus tetap di server-side integration.- Klien Flutter hanya berinteraksi dengan `ELFAN Energy API`.- Token publik berarti autentikasi tidak ada artinya.**Alur yang benar:**```text
Flutter│  GET /energy/growatt/...▼ELFAN Energy API│  GET /growatt/...▼Growatt Integration Service│  Menggunakan token dari environment server```
**Alur yang dilarang:**```text
Flutter│  GET /growatt/...▼Growatt API (token langsung)```
---## 3. Jangan mengubah konfigurasi operasional API kantorDokumen ini hanya **audit dan dokumentasi**. Tugas yang dilarang:- Mengubah API Growatt.- Mengubah konfigurasi operasional API kantor.- Menambah/menghapus perangkat di akun Growatt.- Memperbarui token, base URL, atau skema device di repo `monitoring-inverter`.- Menjalankan perintah yang bisa mengubah state sistem Growatt service.- Menjalankan request yang memodifikasi plant, datalogger, inverter, atau storage.---## 4. Risiko data simulasiRepository ini punya mode `simulate`, yang mengandung data fiktif:- Kurva daya harian berdasarkan jam virtual.- Fault acak.- `dataloggerSn` simulasi `SIM-DL-`.- History 30–180 titik.### Bahaya yang harus dihindari- Menampilkan data simulasi ke laporan energi asli.- Menggunakan history simulasi sebagai histori operasi.- Tidak memberi label ketika data berasal dari simulator.- Menganggap `powerToday` atau `powerTotal` dari mode simulate sebagai nilai nyata.### Label yang harus adaSetiap data diagregat dari source:- `source = growatt/last_new_data`- `source = growatt/invs_data`- `source = local_simulate`- `source = local_snapshot`---## 6. Keterbatasan API historisDokumen PDF mencakup beberapa endpoint historis, seperti:- `/device/inverter/data`- `/device/inverter/alarm`- `/device/inverter/inv_data_info`- `/device/storage/storage_data`Tapi dalam implementasi repository, historis hanya berupa data simulasi local. Artinya:- Historis Growatt aktual belum diverifikasi di kode yang diamati.- Konfigurasi storage/acount, perkiraan rate limit, dan batas query tidak terlihat.- Untuk histori, LLM harus memvalidasi endpoint yang benar di environment yang bisa diakses.---## 7. Hal yang belum diverifikasiBerikut adalah hal yang **tidak dapat dipastikan** dari dokumen dan kode yang tersedia:| Item | Status | Catatan ||---|---|---|| Endpoint `baseUrl` production yang valid | BELUM DIVERIFIKASI | Hanya tahu `test` + beberapa host contoh || Score endpoint `device/datalogger/list` | BELUM DIVERIFIKASI | Terrain dokumen, tidak diuji || Format `pf` 0-1 atau % | BELUM DIVERIFIKASI | Contoh `-1` tidak konsisten || Satuan field `pac`, `ppv`, `vacr`, `vpv` | BERDASARKAN DOKUMENTASI | Konteks PLTS mengarah ke W/V/A/Hz || Speed rate limit exact | BELUM DIVERIFIKASI | `10012` menunjukkan general, tapi antara exact || Format `statusText` kode | BELUM DIVERIFIKASI | Tergantung firmware || History history Growatt yang valid | BELUM DIVERIFIKASI | Simulasi lokal bukan data aktual || `requestTimeoutMs` Growth modal | BELUM DIVERIFIKASI | Default 10-15s di kode, tapi harus uji || Kode error lengkap | BELUM DIVERIFIKASI | `10005`, `10012` terbaca, tapi kode lain tidak || Kode error HTTP farms | BELUM DIVERIFIKASI | Tidak ada data dokumentasi resmi || Kebijakan `retry` dan `backoff` | BELUM DIVERIFIKASI | Kode memiliki daftar retry, tetapi batas lanjut || Implementasi cache di serverless | BELUM DIVERIFIKASI | `api/snapshot.js` menggunakan cache in-memory |---## 8. Checklist keamanan backend ELFAN1. Token Growatt tidak ada di file konfigurasi repo.2. Token diberikan melalui environment atau secret manager.3. Validasi token ada sebelum `growatt` mode.4. Endpoint ELFAN tidak mengirim token Growatt ke klien.5. Batch polling dibatasi, concurrency dikendalikan.6. Request timeout dan retry dipisahkan.7. Response dengan `error_code` dicek sebelum diproses.8. Data `mode: simulate` diberikan label fiktif.9. `mode: simulate` / history simulasi diberi label fiktif, bukan data actual.10. Log mencatat `device_sn`, `baseUrl`, `error_code`, `http_status`, tanpa token.
